# Выбор сеттинга

Минисайт для выбора следующей настольной ролевой игры: SCP Foundation, Wolf Among Us и Vampire: The Masquerade.

Статические HTML, CSS и JavaScript. Сборка не требуется. Главная страница — `index.html`, подборка артов и видео — `materials.html`.

Ответы анкеты сохраняются в браузере и копируются или скачиваются для отправки ведущему. Общая база ответов не подключена.

Визуальные источники и лицензии перечислены в [CREDITS.md](CREDITS.md). Лицензия шрифта — `assets/fonts/OFL.txt`.

Во всех вопросах с вариантами можно отметить несколько ответов. Wolf Among Us и Vampire: The Masquerade ограничены одним городом; опрос собирает предпочтения по городу. У Wolf также выбираются роль команды и известность магии. Старые одиночные ответы автоматически сохраняются как один выбранный вариант. Шкалы интереса остаются от 1 до 10.

Нижняя анкета повторяет только незаполненные вопросы всех сеттингов. Ответы выше сразу убирают соответствующий повтор. Внизу можно отметить несколько вариантов, затем нажать «Готово»; заполненные вопросы исчезнут, а пропущенные останутся. Ответы синхронизируются с описаниями миров и сохраняются в общий экспорт один раз.
